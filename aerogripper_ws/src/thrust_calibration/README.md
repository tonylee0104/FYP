# 力传感器数据分析程序

这个程序用于分析力传感器测出的阶梯形力数据，自动识别每个阶梯并计算平均力值。

## 功能特点

- 自动加载和清理CSV格式的力传感器数据
- 智能检测力数据的阶梯变化点
- 计算每个阶梯的平均力值（x力、y力、z力、合力）
- 生成可视化分析图表
- 导出分析结果到CSV文件

## 数据格式要求

CSV文件应包含以下列：
1. 时间 - 时间戳
2. x力 - X方向力值
3. y力 - Y方向力值  
4. z力 - Z方向力值
5. 合力 - 三个方向力的合成力

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

1. 将您的CSV数据文件放在同一目录下
2. 修改程序中的文件路径（如果需要）
3. 运行程序：

```bash
python force_analysis.py
```

## 输出结果

程序会输出：
- 控制台显示的分析结果表格
- 可视化图表（显示原始数据和阶梯分割）
- 结果CSV文件（force_analysis_results.csv）

## 参数调整

如果需要调整阶梯检测的灵敏度，可以修改以下参数：

- `window_size`: 滑动窗口大小（默认50）
- `threshold_factor`: 变化检测阈值因子（默认0.1）

## 注意事项

- 确保数据文件格式正确
- 程序会自动跳过无效数据行
- 建议数据采样间隔均匀以获得最佳效果
